# RaceDay_POE_Part1
Planning the API web based event management system for race day road events culture. The platforms enables event organisers to create and manage events, categories and participants results.
Participants are enabled to browse upcoming events, enter events, track their results and prepare for the event with live weather forecasting and route information.
There are two roles in this system which is the Organiser and the participant which  their personal information will be captured for the event purposes.
